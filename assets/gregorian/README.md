# Gregorian chant font (Greciliae)

`greciliae.ttf` is the **Greciliae** font from the [Gregorio project](https://github.com/gregorio-project/gregorio),
a square-notation (Vatican/Solesmes style) plainchant font with precomposed neume
glyphs. It is licensed under the **SIL Open Font License 1.1** (see `OFL.txt`),
which permits bundling/redistribution inside this Apache-2.0 package. The font
file is unmodified; the Reserved Font Names ("Caeciliae", "Greciliae") are retained.

`greciliae_glyphnames.json` maps the font's glyph names (stable) to their
Private-Use-Area codepoints (build-order assigned, pinned to this font version),
extracted from this exact `greciliae.ttf` with fontTools.
